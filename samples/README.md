# Sample-аудио

В проекте должны находиться 3–5 собственных коротких аудиофрагментов по сценарию `car_wash`.
Подготовлены пять коротких WAV-файлов длительностью примерно 3–5 секунд.

| Файл | Ожидаемые ключевые слова |
|---|---|
| `01_booking_wash.wav` | мойка, запись |
| `02_body_wash.wav` | мойка, кузов |
| `03_interior.wav` | салон |
| `04_full_service.wav` | запись, мойка, кузов, салон |
| `05_wash_body_interior.wav` | мойка, кузов, салон |
