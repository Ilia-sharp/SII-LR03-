# Sample-аудио

Собственные записи по сценарию `car_wash`: пять коротких WAV-файлов (16 кГц, моно) длиной 2–5 секунд. Исходные файлы (mp3/ogg) конвертируются командой `ffmpeg -i запись.mp3 -ac 1 -ar 16000 -sample_fmt s16 samples/<имя>.wav`.

| Файл | Фраза | Ожидаемые ключевые слова |
|---|---|---|
| `01_booking_wash.wav` | «Здравствуйте, хочу записаться на мойку» | мойка, запись |
| `02_body_wash.wav` | «Нужна мойка кузова» | мойка, кузов |
| `03_interior.wav` | «Пожалуйста, почистите салон» | салон |
| `04_full_service.wav` | «Хочу записаться на мойку кузов и салон» | запись, мойка, кузов, салон |
| `05_wash_body_interior.wav` | «Нужна комплексная мойка кузов и салон» | мойка, кузов, салон |
