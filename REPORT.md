# Отчёт по лабораторной работе №3

## Тема
Транскрипция аудио и поиск ключевых слов.

## Цель работы
Собрать аудиосервис: аудиофайл → декодирование → распознавание речи Whisper/faster-whisper → текст → поиск ключевых слов → API.

## Индивидуальный вариант
Вариант №16 — `car_wash`, «Автомойка».
Ключевые слова: `мойка`, `кузов`, `салон`, `запись`.

## Реализация
Использованы FastAPI, faster-whisper, FFmpeg и YAML-конфигурация. Русский язык задаётся как `language=ru`; Whisper работает на CPU с моделью `base` и `int8`. Модель создаётся при старте приложения и затем переиспользуется для запросов.

Реализованы эндпоинты:
- `GET /health`;
- `POST /transcribe`.

`POST /transcribe` возвращает `scenario_id`, `scenario_name`, `text`, `language`, `segments`, `keywords_found`, `model`, `model_version`, `latency_ms`.

Добавлена обработка пустого файла (400), неподдерживаемого формата (415) и превышения лимита длины более 60 секунд (413). Перед распознаванием входной файл приводится FFmpeg к mono/16 kHz/s16.

Добавлен веб-интерфейс: загрузка/drag-and-drop аудио, быстрый выбор sample-файлов, запуск транскрипции, отображение распознанного текста, найденных ключевых слов, времени обработки и полного JSON ответа API. Отдельный фронтенд-сервер не требуется — интерфейс раздаётся самим FastAPI.

## Тестовые данные
Подготовлены пять коротких WAV-файлов в каталоге `samples/`. Для каждого задан ожидаемый набор ключевых слов.

## Проверка
Unit-тесты проверяют конфигурацию варианта, поиск и подсчёт ключевых слов, `GET /health`, обработку пустого/неподдерживаемого файла и контракт `POST /transcribe`; отдельные тесты проверяют доступность UI и статических ресурсов. Итог: 31 тест проходит успешно. Дополнительно проверены словоформы ключевых слов, ответ 503 при незагруженной модели и JSON-ответ 500 при сбое распознавания. Полный `smoke_test.ps1` дополнительно отправляет все sample-файлы в реально запущенный сервис с faster-whisper.

## Вывод
Разработан CPU-аудиосервис для русского языка, выполняющий декодирование, транскрипцию речи и поиск индивидуальных ключевых слов через REST API. Блокирующие операции (ffmpeg, Whisper) выполняются в пуле потоков, поэтому `/health` отвечает во время распознавания.
